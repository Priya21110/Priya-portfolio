PRIYA PORTFOLIO - VS CODE MEIN KHOLNE AUR CHALANE KI GUIDE

1. Is folder ko VS Code mein kholna
   - VS Code kholo.
   - File > Open Folder par click karo.
   - priya-portfolio folder select karo.

2. Website ko apne laptop par dekhna
   Sabse aasan: index.html par right-click karke Open with Live Server chuno.
   Agar Live Server nahi hai:
   - VS Code ke left side Extensions icon par click karo.
   - Live Server search karke Ritwick Dey wali extension install karo.
   - index.html kholkar neeche status bar mein Go Live click karo.
   - Browser mein website khul jayegi. Save karne par page refresh hoga.

3. Kaunsi file kya karti hai?
   index.html = Website ka content aur structure: naam, about, skills, experience,
                projects aur contact section.
   style.css  = Website ka design: colors, fonts, spacing, cards aur phone layout.
   script.js  = Chhota JavaScript code: footer mein current year dikhata hai.
   README-HINDI.txt = Ye chalane aur customize karne ke steps.

4. Apni details update karna
   - index.html mein Ctrl+H se ypriyaya2004dav@gmail.com dhoondo aur zarurat ho
     to apna preferred contact email rakho.
   - Internship ke actual month/year add karo; filhaal page unhe add karne ko yaad
     dilata hai.
   - MongoDB ya koi bhi technology tabhi rakho jab tumne project mein waqai use ki
     ho aur interview mein samjha sako.
   - GitHub/LinkedIn profile ho to contact section mein links add kar sakti ho.
   - Ctrl+S dabakar save karo.

5. Interviewer ko online link dena
   Abhi website sirf tumhare laptop par hai. Interviewer ko dikhane ke liye ise
   GitHub par upload karke GitHub Pages enable karna hoga. Uske baad ek public URL
   milega jise resume mein Portfolio link ke roop mein daal sakti ho.

   IMPORTANT: Public karne se pehle contact details, internship dates aur har
   project/skill verify karo. Apna phone number public site par tabhi daalo jab
   tum chahti ho ki koi bhi use dekh sake.
